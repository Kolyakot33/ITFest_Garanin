Это - telegram бот, который пересылает новости со страниц ВКонтакте по заданным хэштегам пользователям, которые подписались на них.
Бот предоставляет удобный интерфейс с кнопками для подписки на новости, но также возможно использование простых команд.
Бот работает на [@kolyakot33_bot](https://t.me/kolyakot333_bot)
### Установка
```shell
git clone https://github.com/Kolyakot33/it-fest
cd it-fest
pip install -r requirements.txt
```
#### Далее необходимо добавить токены telegram и VK в config.py.

### Запуск
```shell
python3 main.py
```
